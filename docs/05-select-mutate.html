第1部　データを読む・加工する

列を選ぶ、名前を変える、計算する

select、rename、mutate、arrange。この4つで「高齢化率の高い自治体ランキング」がもうできます。

このページの中身

  • select——列を選ぶ
  • rename——名前を変える
  • その前に——データ型をちらっと見る
  • mutate——新しい列をつくる
  • arrange——並べ替える

はい、では次に、読み込んで df2020 というオブジェクトに入力したデータを、いろいろな形に加工していきましょう。データはいろんなやり方で加工していくことができますが、いくつもの加工プロセスを組み合わせることで、生のデータから「知りたい情報＝エッセンス」を抽出していくわけです。

加工のための基本的な道具を、これから紹介していきます。

df2020 の中身をみると、それぞれの列には各市区町村について、さまざまな年齢層ごとの人口が入っています。また「注釈」のための列もあります。これを元にして、たとえば市区町村ごとの「高齢化率」を知りたかったとしましょう。

高齢化率は65歳以上の人口が総人口に占める割合です。なのでさしあたって必要なのは、各市区町村の名前と総人口、65歳以上人口の列だけです。そのほかは不要なうえ、邪魔くさいので、消えてもらうことにしましょうか。

select——列を選ぶ

そのときに使えるのが select という関数です。具体的には、こうやります。

df2020 %>%
  select(地域,
         `A1101_総人口【人】`,
         `A1303_65歳以上人口【人】`)

df2020 から出発し、そこに select 関数を適用して、「地域」「A1101_総人口【人】」「A1303_65歳以上人口【人】」という三つの項目だけを選んでいるわけです。これで余計な列は消えてくれました。

このように、残したい列を選ぶこともできますが、逆に消したい列を指定して消すこともできます。select(-xxx, -yyy, -zzz) のように書くと、xxxとyyyとzzzの列だけが消えるわけです。

なぜバッククオートで囲むのか

`A1101_総人口【人】` を囲んでいる記号は、シングルクオート（'）ではなくバッククオート（`）です。キーボードでは Shift＋@ で出てきます。

列の名前に日本語や記号、空白が含まれているとき、あるいは名前が数字から始まるときには、これで囲まないとRが名前として認識してくれません。役所のデータを扱っているとしょっちゅう出てきます。めんどくさいですが、慣れてください。

rename——名前を変える

ところで、「A1101_総人口【人】」とか「A1303_65歳以上人口【人】」とか、何だか鬱陶しいですね。これはもとのcsvファイルに原因があるんですが、単に「総人口」「人口_65歳以上」とかなっていればいいのに、余計なかざりがいろいろとくっついています。邪魔くさいので、取り除いてしまいましょう。

そのために使えるのが rename という関数です。「地域」という列名はまだ分かりやすくはあるんですが、コードは常に半角英数字で書かれるものなので、いちいち日本語入力と切り替えてやるのはめんどくさいし、ミスのもとです。これも変えてしまいましょう。

具体的にはこうやります。

df2020 %>%
  select(地域,
         `A1101_総人口【人】`,
         `A1303_65歳以上人口【人】`) %>%
  rename(region = 地域,
         population = `A1101_総人口【人】`,
         population_over65 = `A1303_65歳以上人口【人】`)

だいぶすっきりしましたね。rename は 新しい名前 ＝ 古い名前 の順で書きます。逆に書きたくなるので、ここは注意してください。

このデータを df2020_simple という新しいオブジェクトに格納しましょう。

df2020_simple <- df2020 %>%
  select(地域,
         `A1101_総人口【人】`,
         `A1303_65歳以上人口【人】`) %>%
  rename(region = 地域,
         population = `A1101_総人口【人】`,
         population_over65 = `A1303_65歳以上人口【人】`)

selectで名前も変える

実は select のなかで名前を変えてしまうこともできます。

df2020 %>%
  select(region = 地域,
         population = `A1101_総人口【人】`,
         population_over65 = `A1303_65歳以上人口【人】`)

短く書けるので私はよく使いますが、最初のうちは「選ぶ」と「名前を変える」を分けて書いたほうが、自分が何をしているのかを見失いにくいと思います。

その前に——データ型をちらっと見る

では次に、高齢化率を計算してみましょう。ただ、その前に。df2020_simple をもう一度見てみましょう。

region という文字の下に <chr> というのが見えますね。これは、region という列に格納されたデータが「文字列（character）」として認識されていますよ、ということを意味しています。また、population と population_over65 の下には <dbl> というのが見えますが、これは小数点以下を含んでいる（かもしれない）数字だよ、という意味です（ちなみに <int> だと整数を意味します）。こういうのを「データ型」と言います。データのタイプ、というくらいのことだと考えてください。

数字として認識されていないデータには、足し算引き算かけ算その他の数学的な処理をほどこすことはできません。この場合はたまたま（というか、私がそのように前処理しておいたので）、高齢化率を算出するときのもとになるデータは数字として認識されていますから、このまま計算に入ることができますが、そうでなければデータ型を変換する必要があります。このやり方は10章で改めて説明します。

mutate——新しい列をつくる

では、本筋に戻ります。

高齢化率というのは、人口に占める65歳以上の人の割合です。ということは、population_over65 を population で割り算してやればいいわけです。パーセントで表示したければ、さらに100をかけることになります。ここではパーセント表示を選んでみましょう。mutate という関数を使って、こうやります。

df2020_simple %>%
  mutate(rate_aged = population_over65 * 100 / population)

mutate というのは、新しい列をつくるための関数です。ここでは、population_over65 に100をかけ算し、それを population で割り算して得られる数値を、rate_aged と名付けた列に入力する、という操作をしているわけです。

いちばん右の列に rate_aged が増えているはずです。列がたくさんあって見えないときは view() するか、select(region, rate_aged) で必要な列だけ表示してみてください。

高齢化率を計算したtibbleを新しいオブジェクトdf2020_aged に格納しておきます。

df2020_aged <- df2020_simple %>%
  mutate(rate_aged=population_over65*100/population)

「1行ずつ」計算される

mutate の計算は、すべての行について同時に、そしてそれぞれの行の中だけでおこなわれます。北海道札幌市の行では札幌市の65歳以上人口が札幌市の総人口で割られ、青森市の行では青森市の数字同士で割られる。3万行あっても一瞬で終わります。

これがExcelとの決定的な違いです。Excelでは1行目に数式を書いて、下方向にコピーして……という作業が必要で、そのコピーが1行足りなかったせいで数字が狂う、というのがよくある事故です。Rでは列に対して一度書くだけなので、そもそもその事故が起きません。

arrange——並べ替える

では、少しだけ分析っぽいことをしてみましょう。高齢化率が最も低い自治体は、どこでしょう？　それを計算するには、arrange という関数を使います。こんな感じです。

df2020_aged %>%
  arrange(rate_aged)

mutate によって作った rate_aged という列のデータを見て、この数字の小さい順番にarrange（並べ替え）しなさい、という命令です。

では逆に、高齢化率が高い自治体のランキングをつくってみましょう。やはり arrange の関数を使いますが、ちょっと変化をつけます。

df2020_aged %>%
  arrange(desc(rate_aged))

rate_aged の数字をみて、今度は大きい順番＝降順（Descending order）に並べ替えなさい、という命令です。
