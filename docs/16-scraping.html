第3部　データを集める

ウェブのページから表を取る

この章について

コードは勉強会のものですが、説明文は私（Claude）が意図を推測して書いた下書きです。

役所のサイトに貼られている表を、手で写さずにそのままtibbleにします。使うのはrvestというパッケージです。

このページの中身

  • お題
  • 読み込んで、表にする
  • 取れた表が、ちょっと変
  • ソースを見る
  • 場所を指定する
  • 取れたものを確かめる

役所のサイトを見ていると、csvもExcelも置いていないのに、表だけがページに貼ってあることがよくあります。数字はそこに見えているのに、手で写すしかない。めんどくさ。

でも、あれをそのまま持ってくることもできます。

お題

全国各地にある裁判所の連絡先や住所などのリストを作りましょう。裁判所のサイトには、高裁ごと・地裁ごとに「所在地」のページがあって、支部や簡裁の住所と電話番号が表になって並んでいます。まずは札幌高裁のページを開いて、あの表を手元のtibbleにしてみます。

HTMLを読むのに便利なのがrvestというパッケージです。tidyverseには含まれていないので、最初にインストールしておきましょう。

library(tidyverse)

# install.packages("rvest")
library(rvest)

読み込んで、表にする

やることは二つだけです。ページを読み込んで、表に変える。

"https://www.courts.go.jp/sapporo-h/about/syozai/index.html" %>%
  read_html() %>%
  html_table()

read_html() はそのページのHTMLを丸ごと読み込みなさい、html_table() はそのなかにある表をtibbleに変えなさい、という命令です。ダブルクオーテーションで囲ったURLからパイプ演算子でつないでいるのは、04章でcsvを読んだときと同じ形ですね。

返ってくるのは、tibbleがいくつか入った「リスト」です。一つのページに表がいくつあるかはページによって違いますから、何個返ってきたかを確かめておきましょう。

sapporo <- "https://www.courts.go.jp/sapporo-h/about/syozai/index.html" %>%
  read_html() %>%
  html_table()

length(sapporo)   # 全部でいくつあるか
[1] 1

一つでした。リストのなかの何番目かを取り出すには、二重の角括弧を使います。表が一つしかないので、sapporo[[1]] が目当てのものです。

なぜこれで取れるのかというと、HTMLでは表が <table> という部品で作られていて、html_table() がそれを全部探してきてくれるからです。逆にいえば、見た目が表なのに <table> で作られていないページ——画像になっている、レイアウトで並べているだけ、PDFが貼ってあるだけ——からは取れません。そういうときは別の手を考えることになります。

取れた表が、ちょっと変

さて、sapporo[[1]] の中身を見てみましょう。

# A tibble: 2 × 5
  裁判所名       郵便番号 所在地            電話番号...4        電話番号...5
  <chr>          <chr>    <chr>             <chr>               <chr>       
1 裁判所名       郵便番号 所在地            担当                番号        
2 札幌高等裁判所 060-0042 札幌市中央区大... 代表各種問い合わせ（窓口案内）…… 011-231-420…

あれ? 二つ、おかしなところがあります。

まず、1行目に「裁判所名」「郵便番号」「所在地」「担当」「番号」という、見出しみたいな文字が入っています。データではなくて見出しのはずのものが、1行目に紛れ込んでいるわけです。

もう一つ、列の名前が 電話番号...4 と 電話番号...5 になっています。「...4」なんて、もとのページには書いてありません。

こういうときは、ソースを見れば理由が分かります。

ソースを見る

ブラウザでページの中身を覗いてみましょう。

  1. ブラウザでそのページを開きます。
  2. 調べたい表の上で右クリックして「検証」を選びます（Chromeなら「Inspect」、Firefoxは「調査」）。
  3. 画面の横にHTMLのコードが出てきます。いま選んだ場所が青く光っているので、その周辺を見ます。

光っているあたりは、こうなっています。長い部分は「……」で省いて、読みやすいように改行を入れてありますが、あとは本物のソースです。

<div class="module-sub-page-parts-table">
<table>
  <caption>管内の裁判所所在地一覧</caption>
  <thead>
    <tr>
      <th rowspan="2" scope="col" style="width:16%;">裁判所名</th>
      <th rowspan="2" scope="col" style="width:12%;">郵便番号</th>
      <th rowspan="2" scope="col" style="width:40%;">所在地</th>
      <th colspan="2" rowspan="1" scope="col" style="width:32%;">電話番号</th>
    </tr>
    <tr>
      <th scope="col">担当</th>
      <th scope="col">番号</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td><a href="./sapporomain/index.html">札幌高等裁判所</a></td>
      <td>060-0042</td>
      <td>札幌市中央区大通西11丁目<br>(1)地下鉄東西線……</td>
      <td>代表<br>各種問い合わせ（窓口案内）</td>
      <td>011-231-4200<br><a href="./../../saiban/madoguti/index.html">ダイヤルイン</a></td>
    </tr>
  </tbody>
</table>
</div>

HTMLは、こういう入れ子の構造になっています。<table> で始まって </table> で終わるのが表ぜんたい、<tr> が1行、<th> が見出しのマス、<td> が中身のマス。スラッシュのついたほうが「ここで終わり」の合図です。エクセルのマス目が、括弧で入れ子にされて並んでいるようなものだと思ってください。

さっきの二つの謎も、これで解けます。

<thead> のなかに <tr> が二つありますね。つまり、この表の見出しは2段になっているわけです。1段目に「裁判所名」「郵便番号」「所在地」「電話番号」が並び、2段目に「担当」「番号」が並ぶ。html_table() は1段目だけを見出しとして扱ったので、2段目のほうがデータの1行目に入ってしまった、というわけです。

そして1段目の最後、電話番号のところに colspan="2" と書いてあります。これは「このマスは横に2つ分の幅を占めます」という指定で、だからRのほうでは電話番号という名前の列が二つできてしまう。同じ名前が二つあると区別できないので、Rが後ろに「...4」「...5」と番号をつけて区別した、というわけです。

2段の見出しは、あとで自分で片づける

rowspan は縦の結合、colspan は横の結合です。人が紙で見るぶんには親切なのですが、機械で読むとこうなります。

このさき17章で全国分を集めてから、まぎれ込んだ見出し行を filter() で捨て、電話番号...4 を contact_point に、電話番号...5 を phone に改名します。あのクリーニングは、いまここで見た2段見出しの後片づけをしているわけです。

場所を指定する

ソースを見たついでに、もう一つ収穫があります。表を囲んでいる区画に、名前がついていました。

<div class="module-sub-page-parts-table">
<table>
  ……

html_table() はページにある表を全部拾ってくるので、表が一つしかないこのページでは何も指定しなくても済みました。でも、飾りやナビゲーションが <table> で作られていて、余計な表まで拾ってしまうページもあります。[[2]] のように番号で選べばその場はしのげますが、ページが更新されて表が一つ増えると番号がずれて別の表を取ってくることになる。しかもエラーが出るわけではないので気づけません。

なので、いま見つけた名前を使って、ページのどこを取るのかを指定してやります。

sapporo <- "https://www.courts.go.jp/sapporo-h/about/syozai/index.html" %>%
  read_html() %>%                                    # HTMLを読み込む
  html_nodes("div.module-sub-page-parts-table") %>%  # 読み込みたいノードを指定する
  html_table()                                       # 表に変換する

さっきとの違いは、真ん中の1行が増えただけです。これで「ページ全体の表」ではなく「この区画のなかの表」に絞られました。

length(sapporo)
[1] 1

取れた数は同じ一つですが、意味が違います。「たまたま一つしかなかったから取れた」のではなく、「この区画のなかの表を取った」ことになったわけです。ページが多少変わっても、この名前が同じなら同じ場所を取ってきてくれます。

div.module-sub-page-parts-table って何ですか

呪文のように見えますが、二つに分かれているだけです。前半の div はHTMLの部品の種類で、divは「区画」を表すいちばんありふれた部品。後半の .module-sub-page-parts-table は、その区画につけられた名前で、classと呼ばれます。頭のピリオドが「これはclassだよ」という合図です。

つまり全体で「module-sub-page-parts-tableというclassのついた区画」を指しているわけです。こういう書き方はCSSセレクタと呼ばれるもので、ほかにもいろいろな指定ができます。

書き方意味
tableすべての表
table.tableListtableListというclassのついた表
div.foofooというclassのついた区画
#mainmainというID（id="main"）がついた部品
div.foo tablefooという区画のなかにある表
aすべてのリンク

classはサイトを作った人が付けたものなので、サイトごとに全部違います。だから毎回自分で調べることになります。慣れないうちは、ここでいちばん時間を食います。

classが付いていない、あるいは同じclassが10個あって絞れない、ということもあります。そういうときは目当てのものを囲んでいる一つ上の区画を見るか、検証画面で右クリックして「Copy」→「Copy selector」を選ぶと、ブラウザがCSSセレクタを作ってくれます。長ったらしいものが出てきますが、そのまま貼れば動きます。AIに聞くのも早いです（21章）。

ちなみに html_nodes() とよく似た html_elements() という関数もあって、こちらのほうが新しい正式な名前らしいのですが、どちらでも同じように動きます。この講座では勉強会で書いたコードに合わせて html_nodes() のほうを使っています。

取れたものを確かめる

新しいページを相手にするときは、いつもここで手を止めて中身を見ることになります。

length(sapporo)               # 表がいくつ取れたか
sapporo[[1]] %>% colnames()   # 列の名前
sapporo[[1]] %>% nrow()       # 行数

ブラウザで見えている表と行数が合っているか、列の名前がちゃんと入っているか、さっきのように見出しがデータの1行目として読まれてしまっていないか。ここを飛ばして先へ進むと、あとで必ず戻ってくることになります。要検討

うまく取れていたら、ファイルに書き出しておきましょう。次に必要になったときは、また取りに行かずにこれを読めば済みます。

sapporo[[1]] %>%
  write_excel_csv("output/裁判所連絡先_札幌.csv")

取る前に、そのサイトを見ておく要検討

機械でページを読むというのは、相手のサーバーにアクセスするということです。1ページならブラウザで開くのと変わりませんが、いずれ何十ページも続けて読むことになります。

その前に、そのサイトが機械的な取得を禁じていないかどうかを確かめて下さい。禁止と書いてあれば、担当課に電話して事情を説明してデータをもらったほうが早い場合もあります。そのほうが元データがきれいなことも多いです。それから、同じデータがcsvで公開されていないかどうかも見ておきましょう。あるならスクレイピングする必要はありません。

社内のルールがある場合は、それに従って下さい。ここは技術の問題ではないので、迷ったら先に相談したほうが早いと思います。

宿題

自分の担当分野の役所のサイトから、表が貼られているページを一つ探して、html_table() だけで取れるかどうか試して下さい。取れなかった場合は「検証」でソースを見て、classを調べて html_nodes() で指定してみましょう。

ところで、いま取れたのは札幌高裁のぶんだけです。同じようなページが、仙台にも東京にも、全国にあります。
