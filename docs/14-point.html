第2部　データを見る

散布図

点が多いほど強いグラフ。1700余の市町村をいちどに眺めて、「東京だけ子どもが減っていない」の中身を確かめます。

このページの中身

  • 点をばらまく
  • 色、大きさ、透明度
  • 全市町村を眺める
  • 「なんとなく」を確かめる
  • 対数の目盛りにする
  • 注目したいものだけ色をつける
  • 見栄えを整える

点をばらまく

つぎに散布図です。これは点が平面上にばらばらと散らばったかたちのグラフで、点がたくさんあっても（というか、あればあるほどむしろ）分かりやすいというところが、折れ線グラフと棒グラフに比べて優れています。

というわけで、全都道府県の人口データを可視化していきます。まずはデータを読み込んで、all_pref というオブジェクトに保存しましょう。

all_pref <- read_csv("data/都道府県別人口.csv")

このデータから各都道府県の子どもの割合を計算して、それを散布図で表現してみます。

all_pref %>%
  mutate(rate_under15 = population_under15 * 100 / population) %>%
  ggplot() +
  geom_point(aes(x = year, y = rate_under15))   # ここで散布図を指定

geom_line や geom_col ではなく、geom_point と書くことで散布図を書くように命令しています。横軸に年、縦軸に子どもの割合を表示させると、全体として右肩下がりになっていることが読み取れるグラフになりました。

色、大きさ、透明度

ただ、点がすべて色も形も大きさも同じなので、見分けがつきません。試しに都道府県ごとに違う色をつけてみましょう。

all_pref %>%
  mutate(rate_under15 = population_under15 * 100 / population) %>%
  ggplot() +
  geom_point(aes(x = year,
                 y = rate_under15,
                 color = prefecture))   # 色で分ける

うーん、色が全都道府県分で47種類もあるので、さすがに分かりにくくなってしまいました。

色で分けられるのは、せいぜい7つくらい

これは覚えておくと得をする経験則です。人間が凡例と絵を見比べて区別できる色数は、多くて7つか8つ。それ以上になると、色分けはむしろ邪魔になります。

47都道府県を色分けしたくなったら、次のどれかを考えます。

  • 注目する2〜3個だけに色をつけて、あとは灰色にする（この章の後半でやります）
  • 色ではなく、点の大きさや位置で情報を伝える
  • グラフを小さく分割して並べる（facet_wrap() という関数があります）

つぎに、人口によって点の大きさを変えてみましょう。

all_pref %>%
  mutate(rate_under15 = population_under15 * 100 / population) %>%
  ggplot() +
  geom_point(aes(x = year,
                 y = rate_under15,
                 size = population))   # ここでサイズ指定

size = population と指定することで、人口によって点のサイズを変えるようにしました。このグラフをみると、2010年ごろまで子どもの割合が群を抜いて少なかったところがありますが、これは人口の多い都道府県なんだなということが読み取れますね。おそらく東京都でしょう。

ただ、点と点が重なり合ってしまっているところが、グチャグチャ〜ッとなっているのでちょっと分かりにくい。ここを解決するため、点を半透明にしてみましょう。

all_pref %>%
  mutate(rate_under15 = population_under15 * 100 / population) %>%
  ggplot() +
  geom_point(aes(x = year,
                 y = rate_under15,
                 size = population),
             alpha = 0.1)   # ここで透明度を指定

点と点が重なり合っているところは色が濃くなっているので、どのあたりに点が集まっているのかがボンヤリ見えてきます。半透明にするように指定しているのは alpha = 0.1 という部分で、この数値を1に近づけるほどに色は濃くなり、0に近づけるほどに薄くなります。どれくらいの色合いにするかは、いろいろ試してベストなのを選べばよいと思います。

alpha が aes() の外に書かれていることにも注目してください。データによって透明度を変えたいわけではなく、全部の点を一律に薄くしたいので、外側です。

全市町村を眺める

散布図は点がたくさんあっても分かりやすい、というのを最初に書きましたが、せっかくなので都道府県別ではなく、全市町村のデータを表示してみましょうか。まずはデータを読み込んで、all_municipality というオブジェクトに保存します。

all_municipality <- read_csv("data/市町村別人口.csv")

横軸に年、縦軸に子どもの比率をとったグラフにしてみましょう。先ほどと同じように、人口の多さを点の大きさで表現して、さらに半透明にします。

all_municipality %>%
  mutate(rate_under15 = population_under15 * 100 / population) %>%
  ggplot() +
  geom_point(aes(x = year,
                 y = rate_under15,
                 size = population),
             alpha = 0.1)

なんとなく、ですが、規模の大きい自治体と小さい自治体とで、子どもの割合の下がり方に違いがあるようにも見えます。具体的には、小さい自治体のほうで下落がよりはっきりしているように感じます。

「なんとなく」を確かめる

本当にそうでしょうか。確かめるため、2000年から2020年にかけて子どもの数がどう変化したか、自治体ごとに示したデータをつくっていきます。

以下のようなコードです。pivot_longer にしたと思ったら今度は pivot_wider にしたりしていて、やたら複雑に見えますが、そうしなければならない理由があります。もし興味があれば、パイプ演算子で区切られたところでデータがどんな形をしているか確かめることで、どんなふうに加工されていっているのかを確認してみてください。

all_municipality_change <- all_municipality %>%
  filter(year %in% c(2020, 2000)) %>%
  select(year, code, prefecture, municipality, population_under15, population) %>%
  pivot_longer(cols = c(population_under15, population),
               names_to = "category",
               values_to = "value") %>%
  pivot_wider(names_from = c(category, year),
              values_from = value) %>%
  mutate(change_under15 = (population_under15_2020 * 100 / population_under15_2000) - 100)

なぜlongerとwiderを続けてかけるのか

やりたいのは「1つの自治体につき1行」の形にして、2000年と2020年の数字を同じ行に並べることです（09章でやった、計算は1行のなかで完結する、という話ですね）。

でも pivot_wider は、列名のもとになる列と、中身のもとになる列を1つずつしか受け取れません。いま横に広げたいのは「年」と「人口の種類」の掛け算（2000年の総人口、2000年の15歳未満、2020年の総人口、2020年の15歳未満の4つ）です。

そこでいったん pivot_longer で「人口の種類」を category という1つの列にまとめてしまい、そのうえで names_from = c(category, year) として、2つの列を組み合わせた名前で横に広げているわけです。だから population_under15_2020 のような列名ができます。

面倒に見えますが、この「いったん縦にしてから横にする」は実務でよく出てくる形です。困ったら思い出してください。

「割合の変化」と「数の変化」は別物要検討

いま作った change_under15 の中身をよく見てください。2020年の15歳未満人口を2000年の15歳未満人口で割っているので、これは子どもの数が何％増えたか減ったかです。子どもの「割合」の変化ではありません。

割合の変化を見たいなら、それぞれの年の割合を出してから引き算します。

mutate(rate_2000 = population_under15_2000 * 100 / population_2000,
       rate_2020 = population_under15_2020 * 100 / population_2020,
       change_rate = rate_2020 - rate_2000)

この2つは似ているようで、まったく違う話をします。人口全体が3割減った町で子どもが3割減れば、数は3割減ったのに割合は変わっていない。逆に子どもが2割減っただけなら、数は減っているのに割合は上がります。

グラフの軸に何と書くか、記事に何と書くか。ここを取り違えると、事実と違うことを書いてしまいます。私はこの手の混同を何度もやりかけました。分子と分母が何なのかを、口に出して確かめる。 これが唯一の予防法だと思っています。

以下の作例では、change_under15（数の変化率）をそのまま使います。軸のラベルも「数」で書きます。

横軸に2020年の人口、縦軸に子どもの数の変化率をとったグラフにしてみましょう。

all_municipality_change %>%
  ggplot() +
  geom_point(aes(x = population_2020, y = change_under15))

うーん、左の方にやたら点が集中していて、右の方には少ない。何だかよく分かりませんね。これは人口の少ない自治体の数は多くて、人口が多い自治体は珍しいからです。

対数の目盛りにする

こういうパターンはよくあって、そういうときには「対数グラフ」にしてみると分かりやすくなることがあります。こんな感じです。

all_municipality_change %>%
  ggplot() +
  geom_point(aes(x = population_2020, y = change_under15)) +
  scale_x_log10()

scale_x_log10() というのを最後に付け加えることで、横軸が対数表示に変わりました。対数というのは高校数学で習うはずですが、目盛りがひとつ変わるごとに数字が「倍々ゲーム」で増えるものです。たとえば、目盛りが一つ増えると10倍に、二つ増えると100倍に、三つ増えると1000倍になるというものです。

このグラフだと、子どもの数の変化率が人口規模に対して右肩上がりになっている、つまり人口の多い自治体ほど子どもの減り方が小さい傾向にあることがはっきりしました。

対数グラフを記事に使うときは要検討

自分がデータを探るときには、対数の目盛りはとても役に立ちます。でも読者に見せるときは慎重に。目盛りが等間隔に増えていない図は、慣れていない人にはまず誤読されます。

紙面やウェブで出すなら、

  • 「1目盛りで10倍」であることを図中にはっきり書く
  • あるいは、人口を「1万人未満」「1万〜5万人」といった階級に分けて、階級ごとの平均を棒グラフにする

くらいの気配りが必要です。取材のための図と、読者に見せる図は別物だと考えたほうがいいと思います。

注目したいものだけ色をつける

また、先ほどつくってみたグラフの中で、東京都は子どもの割合が下げ止まっていそうだなぁ、ということが見えていました。その要素をこのグラフに盛り込んでみましょう。そのためにはまず、各自治体を「東京都の自治体」と「その他」に分類し、その分類にもとづいて色分けしてやればよさそうです。コードはこんな感じです。

all_municipality_change %>%
  mutate(area = ifelse(prefecture == "東京都",
                       "東京都の自治体",
                       "その他")) %>%
  ggplot() +
  geom_point(aes(x = population_2020, y = change_under15,
                 color = area),
             alpha = .3) +
  scale_x_log10()

点の重なり合いによって見にくくなるのを防ぐため、半透明にする指示も加えました。東京都の自治体は、規模が小さめでも子どもの減り方がかなり小さいことがみてとれますね。

ifelseは3つセットで覚える要検討

ifelse() は、条件によって値を振り分ける関数です。丸括弧のなかは必ず3つ。

ifelse(条件, 条件に合うとき, 合わないとき)

これは記者の仕事でめちゃくちゃ使います。要検討「政令市かどうか」「過疎地域かどうか」「与党系か野党系か」といった、自分の頭のなかにある分類をデータに持ち込むための道具です。

3つ以上に分けたいときは case_when() を使います。

mutate(kibo = case_when(population >= 500000 ~ "大都市",
                        population >= 100000 ~ "中規模",
                        .default = "小規模"))

上から順に条件を確かめて、最初に当てはまったところで止まります。だから条件を書く順番が大事です。

見栄えを整える

さて、このグラフを同僚に共有して、記事化の可能性について相談したい。でもグラフにはタイトルがないし、縦軸の表示も change_under15 とか英語なのでちょっと分かりにくいし、全体的に少し不親切ですね。というわけで、見栄えにも気をつかってみましょう。こんなコードです。

all_municipality_change %>%
  mutate(area = ifelse(prefecture == "東京都",
                       "東京都の自治体",
                       "その他")) %>%
  ggplot() +
  geom_point(aes(x = population_2020, y = change_under15,
                 color = area),
             alpha = .3) +
  scale_x_log10() +
  labs(title = "全国の市町村における子どもの数の変化",
       subtitle = "2000年から2020年にかけての増減を％で表示。出典は国勢調査",
       x = "2020年の人口",
       y = "15歳未満人口の変化率（％）",
       color = "地域")

labs() の丸括弧のなかでグラフのタイトルとサブタイトルを指定し、さらに縦軸と横軸、凡例のそれぞれが何を示しているのかを日本語で表示するように指示しています。このグラフなら同僚も一目で分かってくれる、はずです。
