プロジェクトとパッケージ

作業場所をひとまとめにする「プロジェクト」と、道具箱にあたる「パッケージ」。この2つを用意すれば準備は終わりです。

プロジェクトをつくる

次に「プロジェクト」を立ち上げましょう。

RStudioの「プロジェクト」は、ファイルやフォルダを整理し、作業環境を管理しやすくするための機能です。データ分析や可視化を進めるとき、分析のためのコードや文書があちこちに散らばってしまうと、どこで何を編集すればいいか分からなくなりがちです。そこで役立つのが「プロジェクト」で、関連するファイルや設定をひとまとめにして管理できます。

プロジェクトを使う最大のメリットは、分析環境の再現性が高まる点です。たとえば「テーマ別」「月ごと」など、記事の枠組みに合わせてプロジェクトを切り分ければ、それぞれのフォルダ内だけでコードやデータをやり取りすることになるため、混乱を防ぐことができます。さらに、プロジェクトごとに作業スペースが独立しているので、一つのプロジェクトを閉じて別のプロジェクトを開けば、作業環境がきれいに切り替わるのも便利です。

新しくプロジェクトをつくるときには、RStudioの画面左上にある「File」から「New Project」→「New Directory」と進み、また「New Project」を選べば、新しいフォルダでそのプロジェクトを始めることができます。既存のフォルダでプロジェクトを始めたい場合には、「New Directory」ではなく「Existing Directory」を選びましょう。「Version Control」はGitHubと連携するためのものらしいのですが、ここではひとまず忘れてください（実は私自身が使いこなせていません……）。

また、すでに作ったプロジェクトは、当該フォルダの中にある .Rproj という拡張子のファイルをダブルクリックすれば開くことができます。

なぜプロジェクトだと「data/人口データ2020.csv」で足りるのか

プロジェクトを開くと、Rはそのフォルダを「いま自分がいる場所」とみなします。だからファイルの場所を書くときも、C:/Users/… みたいな長い住所ではなく、そのフォルダから見た短い住所（data/人口データ2020.csv）で済むわけです。

これは地味ですが大事なことで、コードを同僚に渡したときにもそのまま動きます。長い住所を書いていると、自分のパソコンでしか動かないコードになってしまいます。

フォルダの分け方

プロジェクトのフォルダの中は、こんなふうに分けておくと後で自分が助かります。この講座もこの前提で進めます。

人口分析/                     ← プロジェクトのフォルダ
├── 人口分析.Rproj            ← これをダブルクリックすると開く
├── 分析.Rmd                  ← 書いたコード
├── data/                     ← もとのデータ（絶対に手で書き換えない）
│   ├── 人口データ2020.csv
│   └── 人口データ2015.csv
├── download/                 ← ウェブから落としてきたファイル
└── output/                   ← 出力したcsvやグラフ

大事なのは、data のなかのファイルは手で触らないということです。もとのデータには一切手をつけず、加工はすべてコードのなかでやる。こうしておけば、あとで「この数字、元データではどうなってたっけ」と確かめたいときに、いつでも出発点に戻れます。

Tidyverseを入れる

では、いよいよ作業に入りましょう……と言いたいところなのですが、その前にもうひとつだけ。データの基本的な処理に使われるtidyverseと呼ばれるパッケージをインストールします。

install.packages("tidyverse")

いちどインストールすると、次にRStudioを開いたときからはやらなくて済むようになります。また、実際に使うときには、そのパッケージを呼び出してやる必要があります。

library(tidyverse)

こちらの命令は、次にRStudioを開いたときにも、改めてやり直さなくてはいけません。

install.packages と library の違い

  • install.packages("tidyverse") は「道具を買ってきて棚に置く」。一度やれば二度目はいらない（というか、やると時間の無駄です）。
  • library(tidyverse) は「棚から道具を取り出して机に置く」。RStudioを開くたびに毎回必要。

「昨日は動いたコードが今日はエラーになる」というときの原因は、たいていこれです。Error: object 'read_csv' not found とか 関数 "%>%" を見つけることができませんでした みたいなエラーが出たら、まず library(tidyverse) を実行し忘れていないか確かめてください。

そもそもパッケージとは何か

Rには基本機能のほかに、有志たちが開発したさまざまな道具があります。その道具を束ねたものがパッケージと呼ばれるもので、きれいな表を出力したり、行政機関が持っているデータを呼び出したり、地図データを読み込んで加工したりといった、多種多様な専門的用途に合わせて開発されています。「こんなことがやりたいな」と思ってググってみたら、そのためのパッケージが見つかった、なんてことがよくあります。

tidyverseはあまたあるパッケージの中でも、データ分析をする人たちの間でとくによく使われているものです。dplyrやggplot2など、分析によく使われるパッケージを集めた「パッケージの詰め合わせ」のようなパッケージで、開発者のハドリー・ウィッカムさんはその界隈で神とあがめられています。

RStudioでデータ分析をするときは、まずはじめに library(tidyverse) を実行する、と覚えておいてください。

詰め合わせの中身

tidyverseを呼び出すと、実はこれだけの道具が一度に机の上に並びます。名前は覚えなくていいのですが、「あの機能はこの箱に入っている」という地図があると、あとで調べるときに便利です。

パッケージ何をするものこの講座で出てくる場所
readrcsvなどを読み書きするread_csv write_excel_csv
dplyrデータを加工する主力select mutate filter group_by left_join
tidyr縦長・横長を入れ替えるpivot_longer pivot_wider
stringr文字を切ったり貼ったりするstr_split_i str_sub str_detect
ggplot2グラフを描くggplot geom_line geom_col geom_point
lubridate日付を扱う付録B
purrr繰り返しをすっきり書くこの講座では扱いません

この講座ではほかに、Excelを読む readxl、ウェブを読む rvest、ファイルを落とす httr、いわゆる神エクセルを解体する tidyxl と unpivotr を使います。必要になったところでその都度インストールしていきます。
