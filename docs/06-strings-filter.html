第1部　データを読む・加工する

文字を切り分ける、行を絞り込む

「北海道 札幌市 豊平区」という形式で表現されている自治体名をみっつの列に切り分け、そこからたとえば東京都だけを、人口10万人以上だけを、「市」だけを取り出します。

このページの中身

  • str_split_i——文字を切り分ける
  • filter——条件に合う行だけ取り出す
  • 条件の書き方をもう少し

では次に、都道府県別に高齢化率をみて、ランキングとかをつくっていきましょう。ただ、現状では region の列に自治体名が書いてありますが、「●●県 ●●市 ●●区」のようなかたちでひとまとめにされてしまっています。できればこれを、「都道府県名」「市区町村名」「政令指定都市の区名」といった形で分割したい。そうすれば、後で整理するのが楽になります。

str_split_i——文字を切り分ける

どうすればいいか。考える前に、region の列をよく見てみましょう。すると、都道府県名と市区町村名と特別区名はそれぞれ、半角スペースで区切られていることがわかります。つまり、半角スペースで区切ったうえで、一つ目の要素を都道府県名に、二つ目を市区町村名に、三つ目を区名に格納してやればいいわけです。

たとえば str_split_i という関数を使うと、それが実現できます。mutate 関数を使って、こんな列をつくるわけです。

prefecture = str_split_i(region, " ", 1)

ちょっと難しいですが、str_split_i という関数の丸括弧のなかに、三つの要素が入っています。

  1. 一つ目が、分割する対象。ここでは region という列です。
  2. 二つ目は、分割する目印。半角スペースをダブルクォーテーションで囲って " " としています。
  3. 三つ目は、区切って取り出した文字列の何番目かを示す数字。都道府県名は最初に入っているので、1としています。

つまり、str_split_i(region, " ", 1) というのは、「region という列に入っている文字を半角スペースで区切って、その一つ目を取り出しなさい」という命令。そうして取り出した文字を prefecture という新しい列に格納しているわけです。

municipality という列と ward という列も、ほぼ同じやり方でつくることができます。上記の説明をみれば、わかりますね。新しい列をつくったデータフレームを上書き保存しましょう。

df2020_aged <- df2020_aged %>%
  mutate(prefecture = str_split_i(region, " ", 1),
         municipality = str_split_i(region, " ", 2),
         ward = str_split_i(region, " ", 3))

みっつの列が作られました。

札幌市の行は municipality に「札幌市」が入って ward は空っぽ、中央区の行は ward にも「中央区」が入っています。この違いが、あとで集計するときに効いてきます。

上書きするということ

df2020_aged <- df2020_aged %>% ... は、加工した結果を同じ名前のオブジェクトに入れ直す、つまり上書きするコードです。便利ですが、危なくもあります。

たとえばこのコードを2回実行しても結果は変わりませんが（同じ列を作り直すだけなので）、もし途中に select で列を捨てるような処理が入っていると、2回目には「捨てた列がないぞ」とエラーになります。「あれ、さっきは動いたのに」というときは、たいていこれです。

そういうときは、読み込みのコードから順に上から流し直す。R Markdownに手順を書き残しておくのは、こういうときのためでもあります。

ちなみに文字列の操作には、このように分割するもの以外にも、複数の文字列をくっつけたり、あるいは何らかの文字が含まれているかどうかを判断したり、「●文字目から●文字目までを取り出しなさい」と命令したり、あるいは文字数を数えたりと、いろいろなものがあります。いちいち説明しているとキリがないので省きますが、これらの命令をうまく組み合わせることで、データを自分の望むかたちに加工していくことができます。

こうした各種文字列操作の命令は、stringrというパッケージに入っているのですが、stringrはtidyverseの中に含まれています。名前が str_ で始まるのが目印です。よく使うものは付録Bにまとめました。

filter——条件に合う行だけ取り出す

話が少しそれました。本筋にもどって、高齢化率を都道府県別に見ていきましょう。

それに使えるのが filter 関数です。こんなふうに使います。

df2020_aged %>%
  filter(prefecture == "東京都") %>%
  arrange(desc(rate_aged))

1 檜原村             2003      52.8
2 奥多摩町           4750      50.7
3 八丈町             7042      39.8
4 新島村             2441      39.6
5 三宅村             2273      39.3
6 日の出町          16958      38.6
7 大島町             7102      38.2
8 青梅市           133535      31.8
# ℹ 54 more rows

檜原村、奥多摩町、八丈町。都内といっても、山と島が上位に並びました。

filter という関数は、特定の「行」だけを抽出しなさい、という命令です。この場合だと、prefecture が「東京都」になっている行だけを取り出しなさい、と命令しています。等号（=）がふたつ続けられて == になっていますが、これが「prefecture が『東京都』に等しい」という条件づけをしています。

イコールは2つ

初心者はふたつ続けるのを忘れがちだということが国連の研究で知られています。ここ、注意してください。

  • == は「等しいかどうかを確かめる」
  • = は「等しくする（＝代入する）」

filter(prefecture = "東京都") と書くとエラーになります。エラーメッセージには「== を使うつもりでしたか？」と親切に書いてあることも多いので、落ち着いて読んでください。

filter を使うときの条件設定には、== 以外にもあります。たとえば人口が10万人以上の自治体についてだけ調べたいとしましょう。そのときには、こんなふうに使えます。

df2020_aged %>%
  filter(population >= 100000) %>%
  arrange(desc(rate_aged))

population という列に含まれた数字が、100000以上である行だけを取り出す、という操作をしているのがわかりますね。

また、たとえば町村部をふくまない「市」についてだけ調べたい、とかいうこともあると思います。ちょっと複雑ですが、こんなふうにやれば条件を指定できます。

df2020_aged %>%
  filter(str_sub(municipality, -1, -1) == "市") %>%
  arrange(desc(rate_aged))

str_sub() という関数は、「●番目から●番目までの文字を抽出しなさい」という命令です。この場合は「municipality という文字列のうち、後ろから数えて1番目の文字から、後ろから数えて1番目の文字まで（まだるっこしいですが、要するにいちばん最後の文字）を抽出しなさい」という意味です（マイナスの記号が「後ろから数えて」というのを意味してるわけですが、マイナスをつけなければ前から数えることになります）。そうやって取り出した文字が「市」である行だけを取り出しなさい、という命令になっています。

自治体名に「市」を含むものを抽出する、という単純な命令にしなかったのは、たとえば兵庫県にある「市川町」みたいなのを含まないようにするための工夫です。

だいぶ複雑になってきたような気がします。一つひとつの命令が何をやっているのか、確認しながら読み進めてください。実際に自分でプログラムを書いて、エラーが出たときに「なぜだろう？？？」と考えながらやっていくと、理解が深まってくるはずです。

条件の書き方をもう少し

filter の丸括弧のなかには、いろいろな条件を書けます。よく使うものを並べておきます。

filter(population >= 100000)              # 10万以上
filter(population < 5000)                 # 5000未満
filter(prefecture != "東京都")             # 東京都以外
filter(is.na(ward))                       # wardが空っぽの行だけ
filter(!is.na(ward))                      # wardが空っぽでない行だけ
filter(prefecture %in% c("東京都", "大阪府"))   # どれかに当てはまる
filter(str_detect(municipality, "町"))     # 「町」という字を含む
filter(population >= 100000, rate_aged >= 30)  # 両方を満たす（AND）
filter(prefecture == "東京都" | prefecture == "大阪府")  # どちらか（OR）

コンマで区切って条件を並べると「かつ（AND）」、| でつなぐと「または（OR）」になります。! は「〜でない」という意味で、条件をひっくり返す記号です。

全角と半角、それに空白

filter() で条件を設定して絞り込んだところ、結果はからっぽ、0行になってしまった。こういうことはよくあります。たいていはこんな理由です。

  • 名前の前後に空白が入っている（"東京都 "）
  • 全角の空白と半角の空白が混じっている
  • 「ケ」と「ヶ」、「﨑」と「崎」のような異体字（11章で痛い目にあいます）

前後の空白は str_trim() で取れます。str_squish() なら途中の連続した空白もまとめてくれます。役所のデータを読み込んだら、まずこれをかけておくと平和です。
