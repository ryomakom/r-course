行列とは

「行列」といっても、「行列のできるラーメン屋さん」とかの行列ではありません。エクセルのように、マス目が縦横に並んでいて、その中に数字とかのデータが入っているものを「行列」と呼びます。「3行目の4列目」みたいに言えば、マス目の一つ一つを指定することができます。

で、ここで問題になるのが、行と列って、どっちがどっち？　「3行目の4列目」って、上から3つめで左から4つめってこと？　それとも上から4つめ、左から3つめのことか？

こたえは前者。覚え方もあります。「行」っていう漢字のつくりの上のところに、横に平行な線が2本並んでるでしょ。というわけで、横に平行に並んでるのが「行」です。一方で、「列」という漢字のつくりには、縦棒が2本並んでますね。というわけで、縦に平行に並んでるのが「列」。こうやって覚えてください。

この講座では、

  • 行を絞る → filter()
  • 列を選ぶ → select()

というふうに、行と列で使う関数が違います。ここが混ざると混乱するので、上の覚え方は本当に役に立ちます。

代入と、名前

記号意味
<-代入。A <- 3 は「3という数字をAという変数に入力しなさい」
=記号の左右にある値を等しくする。代入を意味する <- と似ているが、関数の中で使われることが多いという違いがある
==記号の左右にある値が等しいかどうかをチェックする。A == 3 は、Aが3と等しければTRUE、等しくなければFALSE

<- は Alt＋マイナス（MacはOption＋マイナス）で入力できます。

イコール記号は混乱を招く可能性があります。代入は <-、比較は ==、関数の中で引数を指定するときは =。この3つを使い分けます。

演算子

記号意味
+ -足す、引く
* /かける、割る
> <より大きい、より小さい
>= <=以上、以下
==等しい
!=等しくない
%in%並んだもののどれかに当てはまる
%>%パイプ演算子。左のものを右の関数に渡す

ブール論理

TRUEかFALSEかで考える論理のことです。filter() の条件を組み合わせるときに出てきます。

記号意味
&AND（かつ）。両方の条件を満たすもの
|OR（または）。どちらかの条件を満たすもの
!NOT（〜でない）。条件をひっくり返す

ベン図で言えば、A & B は2つの円が重なったところ、A | B は2つの円のどちらかに入っているところ全体、!A はAの円の外側です。

filter() のなかでコンマで条件を区切ると、& と同じ意味になります。

filter(population >= 100000, prefecture == "東京都")   # コンマ
filter(population >= 100000 & prefecture == "東京都")  # 上と同じ意味

引用符と、かたまり

数字ではない「テキスト」や「日付」は、引用符で囲んで入力します（たとえば "Japan" や "2025-02-10" のように）。

2つ以上の値をリストとして入力する場合は、コンマで区切って c() で結合します。

c("Japan", "2025-02-10")

コロンを使うと値の範囲を指定できます。1:10 は1から10までの整数を示します。

記号意味
"..."文字列。ダブルクオーテーション。シングル（'...'）でも動くが、ダブルが慣習
`...`バッククオート。列名が日本語だったり空白を含んだり数字で始まるときに囲む
c(...)値を並べたかたまりを作る
1:101から10までの連続した整数
#これより右はコメント。人間のためのメモで、実行されない
.パイプで渡ってきたものを指す。渡す位置を明示したいときに使う

引用符とバッククオートを混同しないこと。 "population" は「populationという文字そのもの」ですが、`population` は「populationという名前の列」です。意味が違います。

データ型

tibbleを表示したときに、列名の下に出てくる記号です。

記号名前中身
<chr>character文字列。計算はできない
<dbl>double小数を含みうる数値
<int>integer整数
<lgl>logicalTRUE か FALSE
<date>Date日付
<fct>factor決まった選択肢のどれか。グラフの並び順を決めるときに使う

型を変える関数は as.double()、as.character()、as.integer()、as.Date() です。

NA——空っぽということ

NA は Not Available、つまり「値がない」という状態を表します。ゼロではありません。「まだ分からない」「集計されていない」という意味です。

だから、NAを含む計算の答えもNAになります。

sum(c(1, 2, NA))         # NA になる
sum(c(1, 2, NA), na.rm = TRUE)   # 3 になる

NAかどうかを判定するには is.na() を使います。x == NA とは書けません（「分からないものと等しいかどうか」は判定できないので、答えもNAになってしまいます）。ここは引っかかりやすいところです。

filter(is.na(population))    # 空っぽの行
filter(!is.na(population))   # 空っぽでない行

似たものに NULL（そんな列は存在しない）、NaN（0÷0のような計算不能な結果）、Inf（無限大。1÷0など）があります。割り算をしたあとに Inf が出てきたら、分母がゼロの行があるということです。

オブジェクト、関数、引数

  • オブジェクト……データや数字のかたまり。df2020 のように名前をつけて呼び出す
  • 関数……何かをする命令。select() のように、名前のあとに丸括弧がつく
  • 引数（ひきすう）……関数の丸括弧のなかに書く指定。read_csv("data/x.csv", skip = 8) の skip = 8 の部分

「引数」は説明書を読むときに必ず出てくる言葉です。「skip引数に数字を渡す」というのは、「丸括弧のなかに skip = 8 と書く」ということです。

助けを呼ぶ

関数の使い方を忘れたときは、? を頭につけて実行すると説明書が出ます。

?pivot_wider

右下の枠に英語の説明が出てきます。いちばん下まで行くと Examples があるので、そこだけ読むのが実用的です。上から順に読もうとすると、たいてい心が折れます。
