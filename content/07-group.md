では次に、都道府県別の高齢化率を見ていきましょう。

ただ、今のデータでは市区町村ごとの人口データはありますが、都道府県別にまとまってはいません。各市区町村を都道府県別に割り振り、人口を足し上げてやる必要があるわけです。

## group_byとsummarize

そのために使えるのが `group_by` と `summarize` という関数です。こんなふうに使います。

```r
df2020_pref <- df2020_simple %>%
  filter(is.na(ward)) %>%
  group_by(prefecture) %>%
  summarize(pref_population = sum(population),
            pref_population_over65 = sum(population_over65))
```

`group_by` 関数を使ってデータを `prefecture` によってグループ化したうえで、それぞれのグループについて `summarize` 関数を使って総人口と65歳以上人口を足しあげ、それぞれ `pref_population` と `pref_population_over65` という列に格納しています。`sum(population)` という部分は `population` を足し算するという意味で、`sum(population_over65)` はもちろん `population_over65` を足し算するという意味です。

```out outputs/07-pref.txt
```

47行になりました。Excelのピボットテーブルを使ったことがあれば、あの「行に都道府県、値に人口の合計」という操作とまったく同じことをしていると考えてください。

なお、並び順が五十音でも人口順でもなく妙に見えるのは、`group_by` が文字コードの順番で並べているからです。気になるなら `arrange()` で並べ直してください。

## 二重計上に気をつける

また、ちょっと話がそれますが、2行目で `filter(is.na(ward))` という操作をしているのは、**二重計上を防ぐため**です。政令指定都市のデータは市のデータと区のデータの両方があるからです。

`is.na(ward)` というのは、「`ward` という列がNAつまり欠損値（Not Available）である」という意味です。この条件に合う行だけを抽出することによって、政令指定都市の区を除外しているわけです。

そうして作った都道府県別の人口データを、`df2020_pref` というデータフレームに格納する。上記のコードは、そういう命令を書き記したものです。

:::warn 合計は必ず答え合わせする @要検討
足し算をしたら、答えが合っているかを外の数字と照らし合わせる。これは絶対にやってください。

```r
df2020_pref %>%
  summarize(zenkoku = sum(pref_population))
```

```out outputs/07-zenkoku.txt 126146099
```

2020年国勢調査の総人口は1億2614万6099人。ぴったり合いました。合っていなければ、どこかで二重に数えているか、どこかを落としています。

もし `filter(is.na(ward))` を忘れていたら、政令指定都市の人口（20市で2800万人ほど）が2回数えられて、答えは1億5千万人あたりまでふくらみます。2割以上ずれるので、答え合わせをすれば必ず気づけます。逆にいえば、答え合わせをしないと気づけません。
:::

## summarizeで使えるもの

`sum()` のほかにも、いろいろな集計ができます。

```r
df2020_simple %>%
  filter(is.na(ward)) %>%
  group_by(prefecture) %>%
  summarize(jichitai_su = n(),                    # 自治体の数を数える
            gokei = sum(population),              # 合計
            heikin = mean(population),            # 平均
            chuuou = median(population),          # 中央値
            saidai = max(population),             # 最大
            saishou = min(population))            # 最小
```

`n()` は「このグループに何行あるか」を数える関数です。丸括弧のなかに何も入れないのが特徴で、自治体の数、事件の件数、企業の数といった「件数」を出すときに大活躍します。

:::tips 平均と中央値は並べて出す @要検討
人口や所得のように、極端に大きい値が少しだけあるデータでは、平均が実感からずれます。全国の市区町村の人口を平均すると7万人あたりになりますが、中央値は2万人台。「平均的な自治体」と書くときにどちらの数字を指しているのか、記事にする前に自分で確かめておきたいところです。

だから私は、`mean()` と `median()` はいつも並べて出すようにしています。ずれが大きければ、それ自体が記事の切り口になります。
:::

:::warn NAがあると合計がNAになる @要検討
`sum()` は、足す数字のなかに一つでもNA（欠損値）があると、答えもNAになります。「何も出てこないぞ」というときは、まずこれを疑ってください。

```r
sum(population, na.rm = TRUE)
```

`na.rm = TRUE` を足すと、NAを飛ばして計算してくれます。ただし、**気軽に付けないでください**。NAを飛ばすというのは「そこは無かったことにする」という判断なので、なぜNAなのかを確かめないまま付けると、集計の意味が変わってしまいます。

たとえば秘匿処理でNAになっているなら「集計できていない自治体がある」と注記すべきですし、そもそも読み込みの失敗でNAになっているなら、直すべきなのは読み込みのほうです。まずNAがどこにいくつあるかを見る。

```r
df2020_simple %>% filter(is.na(population))
```
:::

## group_byを解除する

`group_by` したあとのtibbleは、グループ化された状態のまま残ることがあります。`summarize` を使うとふつうは解除されますが、`mutate` などを続けて使うときには、そのままだと思わぬ計算結果になることがあります。

```r
df2020_simple %>%
  group_by(prefecture) %>%
  mutate(kensu = n()) %>%
  ungroup()            # グループ化を解除する
```

上のコードは、都道府県ごとの自治体数を、行を減らさずに新しい列として足すというものです（`summarize` は行をまとめてしまいますが、`mutate` なら元の行がそのまま残ります）。この使い方は「全体に対する比率」を出すときに便利です。

最後に `ungroup()` を付ける癖をつけておくと、後々の事故が減ります。
