## Rを入れる

1. まず、Rの公式サイト（[CRAN](https://cran.r-project.org/)＝シーラン）にアクセスします。
2. 自分のコンピューターのOS（WindowsやMacなど）に合ったインストーラーをダウンロードします。
3. ダウンロードしたファイルをダブルクリックして、画面の指示に従ってインストールを進めます（ほとんどの場合、特別な設定は必要ありません）。

## RStudioを入れる

1. [RStudioのダウンロードページ](https://posit.co/download/rstudio-desktop/)にアクセスし、無料の「RStudio Desktop」版をダウンロードします。
2. ダウンロードしたファイルをダブルクリックして、画面の指示に従ってインストールを進めます。
3. インストールが完了すると、RStudioが起動します。すでにインストールされているRを自動的に認識してくれます。

これで準備は完了です。

:::warn 会社のパソコンで入れられないとき
社内のパソコンだと、勝手にソフトを入れられない設定になっていることがあります。その場合はシステム担当に相談してください。R本体とRStudioの2本立てだという点、どちらも無料で商用利用も可能だという点を伝えると話が早いと思います。
:::

## RStudioの画面

![RStudioを起動した直後の画面。左にコンソール、右上にEnvironment、右下にFilesの区画がある](images/02-rstudio.png "起動直後のRStudio。区画の役割を覚えてしまえば、あとは慣れです")

インストールできたRStudioを開いてみましょう。最初の画面は3区画に分かれています。

### 左側——Console（コンソール）

コンピューターに実行させたい命令を「コード」と呼ばれる文章にして、ここに打ち込みます。画面に `>` という記号が出ているときは、命令を聞く準備がととのっていますよ、さあどうぞ命令してください、という合図です。

一方で `+` の記号が出ているときは、前に入力した命令が最後まで終わっていませんよ、という意味です（コンピューターが「からの～～～？」と聞いてきている状態です）。閉じ括弧を忘れたときによく出ます。**Escキーを押せば `>` の状態に戻すことができます**。

### 右上——EnvironmentとHistory

「Environment（環境）」タブでは、いまRStudioで扱っているデータなどにどんなものがあるのかを確認できます。最初はまだ何のデータも読み込んでいないので、空っぽになっています。

「History（履歴）」タブには、コンソールですでに実行された命令が記録されています。

### 右下——Files、Plots、Packages

「Files」では、作業中のフォルダの構造やファイルが確認できます。「Plots」ではデータから作成したグラフや表などが、「Packages」では、インストール済みで利用可能なパッケージの一覧が見られます（パッケージとは何かというのは[次の章](03-project.html)で説明しますので、ひとまず忘れてください）。

### もう一つ必要な区画——コードを書き残す場所

作業にはもう一つの区画が必要になります。データ処理や分析の手順を一連のコードとして書き残し、保存するための場所です。R MarkdownやR Scriptなどの形で保存しておくことができますが、ここではR Markdownでのやり方を書いていきます。

![RStudioのFileメニューからNew File→R Markdownを選ぶ操作を示した画面](images/02-new-rmd.png "File → New File → R Markdown")

左上にある「File」をクリックし、さらに「New File」→「R Markdown」と進んでいくと、ファイル名の最後の部分（拡張子）が `.Rmd` となっているR Markdownの新しいファイルを開くことができます。

この区画は、コードを保存しておくための場所です。データ分析の過程は試行錯誤の連続ですので、コンソールの区画を使っていろいろなコードを実行して、結果がどうなるかをみてみる必要がありますが、試した結果うまくいって、**後に残しておきたくなったコードをR Markdownのほうに書いておく**わけです。

また、R Markdownはコンピューターに実行させる命令を書いておくコードの部分と、人間のための（コンピューターには読ませない）メモを書いておくMarkdown部分に分かれています。保存したうえで、htmlやPDFなどの形式で出力することもできます。

:::note コードの部分の作り方
R Markdownのなかで、コードを書く場所（チャンクと呼びます）はこんな形をしています。

````text
```{r}
library(tidyverse)
```
````

この三つのバッククオートで挟まれた中に書いたものだけが、Rの命令として実行されます。外側に書いた文字は、ぜんぶ人間向けのメモとして扱われます。チャンクを作るのは Ctrl＋Alt＋I（MacはCmd＋Option＋I）が早いです。
:::

## その他、覚えておくと楽になるキー操作

最初のうちはマウスでちまちま実行してもいいのですが、この三つだけは早めに覚えると作業がラクになります。

| キー | 何が起きるか |
|---|---|
| Ctrl＋Enter | カーソルがある行（または選択した範囲）のコードを実行する |
| Ctrl＋Shift＋M | パイプ演算子 `%>%` が出てくる（これが何をするものかはまた後ほど） |
| Ctrl＋Shift＋Enter | いま書いているチャンクを丸ごと実行する |

MacではCtrlをCmdに読み替えてください。

それからもう一つ。このサイトでは、コードを書いている部分はコピペができないようにしています。コードをよく見て、自分で手を動かして同じものを書くという訓練が、Rの各種コマンドや文法を覚えるうえでとても役に立つと思うからです。

Rに限らずプログラミング言語は、ちょっとした文法ミスでエラーが頻発します。それはたとえば変な場所に意図しない記号が紛れ込んでいたりとか、半角にすべきところを全角にしてたりとか、非常にささいなものです。何でエラーが出るんじゃぁといらいらすることは多々ありますが、そういうのを繰り返すうちにはまりやすいパターンもわかり、また文法やコマンドがだんだんと身についてくるわけです。

寺子屋みたいな古い学習法のようにも思えますが、**とにかくまずは手を動かす**。我慢しておつきあいください。
