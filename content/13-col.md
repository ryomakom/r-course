## geom_colに変えるだけ

ではつぎに、棒グラフを作っていきます。折れ線グラフと同じように、東京都の人口データを可視化してみましょう。コードは折れ線グラフのときと、ほとんど変わりません。

```r
tokyo %>%
  ggplot() +
  geom_col(aes(x = year, y = population))
```

![東京都の人口の推移を棒グラフで示したもの](images/13-col-tokyo.png "geom_colに変えるだけで棒グラフになる")

コードは、折れ線グラフで `geom_line` としていたところを `geom_col` としただけです。colはたぶん、「柱」を意味するcolumnの略。これで東京都の人口が増え続けていることを示す棒グラフができたはずです。

:::note geom_colとgeom_barの違い
ggplotには `geom_bar()` という、名前がいかにも棒グラフっぽい関数もあります。ただしこれは**行数を勝手に数えて**棒の高さにするものです。「都道府県ごとの件数」みたいな数え上げのときには便利ですが、手元にすでに集計済みの数字があるときに使うと、思った高さになりません。

**すでに数字がある → `geom_col()`。数えてほしい → `geom_bar()`。** ふだんの仕事では `geom_col()` のほうが圧倒的に多いはずです。
:::

## 積み上げ棒グラフ

ただ、これも1色しかないので少し寂しい気もします。年代別に色分けして、各年代でどんな増減があったかを可視化してみましょう。

```r
tokyo %>%
  select(-population) %>%
  pivot_longer(cols = -c(year, prefecture),
               names_to = "category",
               values_to = "value") %>%
  ggplot() +
  geom_col(aes(x = year, y = value, fill = category))
```

![東京都の人口を3つの年齢層に分けて積み上げた棒グラフ](images/13-col-stack.png "年齢層ごとに色分けした積み上げ棒グラフ")

はじめに `select` 関数で `population` の列を除外しているのは、年代別の人口を積みあげた棒グラフにしたいのに、全体の人口を示すこのデータが残っていると二重計上になってしまうからです。

そのうえで `pivot_longer` 関数をかけて、人口の数値はすべて `value` 列に入るように加工しています。なぜなら、**ggplotで「縦軸にこれを使いなさい」と指定できるのは一つの列だけ**だからです。縦長のデータになっていないと、人口は `population_under15` と `population_15to64`、`population_over65` という三つの列に分かれてしまっていますが、ggplotで縦軸上に（あるいは横軸上に）表現したいデータは、すべて一つの列に格納されている必要があるのです。

そのうえで、`fill = category` というところで「categoryごとに色分けしなさいね」と指示しています。

## colorとfillの違い

折れ線グラフのときは、色分けは `color = ●●` とやっていたのに、今回は `fill = ●●` です。ややこしいですが、折れ線のときは色つきの線を描いていたのに対し、今回は四角い形で表現された棒の中身を色で「埋めて」いますよね。だからfillになるんだ、と私は解釈しています（この解釈が正しいか、裏は取っていませんが）。

ともあれ、縦軸と横軸にそれぞれ、可視化したい列の名前を指定するというggplotの基本は、折れ線のときと変わりません。

:::tips 面には fill、線には color
実用的には、こう覚えておけば足ります。

| 描くもの | 中身の色 | 輪郭の色 |
|---|---|---|
| 折れ線 `geom_line` | — | `color` |
| 棒 `geom_col` | `fill` | `color`（縁取り） |
| 点 `geom_point` | `color`（`shape`次第で`fill`も） | — |

棒グラフで `color` を指定すると、棒の**縁**だけが色づいて中は灰色のまま、という残念な絵ができます。「色分けしたのに変わらない」と思ったら、この2つを取り違えていないか確かめてください。
:::

## 横に並べる棒グラフ

今回は「積み上げ型」の棒グラフになりましたが、つぎに各年代の人口を示す棒が横に並んだグラフにしてみましょう。こんなコードです。

```r
tokyo %>%
  select(-population) %>%
  pivot_longer(cols = -c(year, prefecture),
               names_to = "category",
               values_to = "value") %>%
  ggplot() +
  geom_col(aes(x = year,
               y = value,
               fill = category),   # ここまでは同じ
           position = "dodge")
```

![3つの年齢層の棒が横に並んだ棒グラフ。65歳以上だけが増えている](images/13-col-dodge.png "横に並べると、増えているのが65歳以上だけだと分かる")

といっても、先ほどのコードとほぼ同じ。`geom_col()` の丸括弧の中で `position = "dodge"` と指定したのが唯一のちがいです。dodgeというのはドッジボールのドッジで、「かわす」という意味があります。できあがったグラフをみると、増えているのはほぼ65歳以上の人口だけなのだな、ということがわかりますね。

ここで気をつけたほうがいいのは、`position = "dodge"` という記述が **`aes()` の丸括弧の外側**にあるということです。コンマでつなぐことによって、階層構造的にみて `aes()` と同じレベルのところにあるのです。丸括弧の中に入れてしまうと、エラーが出ます。

これまで見てきた `color` とか `fill` は、横軸と縦軸を示すxとyの二つと同じレベルにありましたが、`position` はその一つ上のレベルにあるのです。`position` は都道府県ごとに変わるものではなく、グラフ全体の並べ方の指定だから、外側に書くわけです。

## 5都府県の子どもの数

ではつぎに主な5都府県の子どもの数を、積み上げ式ではなくて横にずれた棒グラフで表現してみましょう。コードはこうなります。

```r
five_pref %>%
  ggplot() +
  geom_col(aes(x = year, y = population_under15, fill = prefecture),
           position = "dodge")
```

![5都府県の15歳未満人口を横並びの棒グラフで比較したもの。東京都だけが増えている](images/13-col-five.png "東京都だけ、子どもの数が増え続けている")

東京都でのみ、子どもの数がわずかながら増え続けていることがわかりますね。

全国的に子どもが減っているというのは誰でも知っていますが、東京だけは増えている。なぜか。他の県から人が移ってきているのか、それとも都内で生まれる子が多いのか。データはそこまで答えてくれませんが、「どこを取材すべきか」が分かることがあります。
